# VectorPulse v0.3.0

Adds a C++ CPU HNSW index for append-only approximate cosine Top-K search.
M, efConstruction and efSearch are configurable; read-only searches can run
concurrently. Existing exact CPU/CUDA algorithms and Python exact-search APIs
retain their behavior. The compiled HNSW defaults remain M=16,
efConstruction=200, efSearch=50.

Validation on 113,287 COCO CLIP image embeddings (512 dimensions, 500 queries,
K=10) achieved 99.62% Recall@10 at efSearch=80 and 99.92% at 160, closely
matching hnswlib 0.8.0. Recommended starting settings for structured embeddings:
M=16, efConstruction=200, efSearch=80; choose 160 for higher recall.
Construction remains substantially slower than hnswlib. These measurements do
not establish performance on all embedding workloads.

HNSW has no deletion, persistence, Python binding or CUDA implementation in
this release. The historical synthetic parameter sweep remains incomplete;
the completed random/clustered controls and real-data validation are documented.

See [HNSW API](../hnsw.md) and the
[diagnostic report](../benchmarks/hnsw-real-embeddings.md) for measurements,
methodology, limitations and reproduction commands.
